# Ballet Lucero del Alba — Sitio + Panel
HTML/CSS/JS + Supabase (datos y login) + Vercel (hosting).

## Configurar (una sola vez)
Pegar en `assets/config.js` la **Project URL** y la **anon key**
(Supabase → Project Settings → API).

## Probar en tu compu
Sin instalar nada: instalá la extensión "Live Server" en VS Code,
clic derecho sobre index.html → "Open with Live Server".

## Subir cambios
Control de código (VS Code) → mensaje → Commit → Sync.
Vercel se actualiza solo.
